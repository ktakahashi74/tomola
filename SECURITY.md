# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately, through GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue, pull request or discussion about a suspected vulnerability.

A useful report includes:

- the commit or version you tested;
- what the problem is and what an attacker could do with it;
- steps to reproduce, using test data.

Do not include real personal data, credentials, or content taken from a running site. If you need to show data, use a local instance with test accounts.

We will acknowledge the report, work with you on a fix, and agree with you on when and how the problem is disclosed.

## Scope

This policy covers the tomola software in this repository. For a problem with a particular site that runs tomola (its accounts, content or operation), contact that site's operator; each site publishes its own contact details.

## Supported versions

Fixes are made on the `main` branch. There are no separately maintained release branches.
