# tomola 这个名字

Unverified machine translation

我选择 tomola 这个名字，是希望人们能在尽可能多的语言中，自然地发音和称呼它。to、mo、la 这三个音，都由一个辅音和一个元音组合而成，这种形式的音在几乎所有语言中都有。

此外，这个名字在一些语言中，也能读出有意义的词语。

tomo 来自希腊语 tomos，原意是“切分出来的一部分”。经过拉丁语 tomus，在西班牙语、意大利语、葡萄牙语的 tomo、俄语的 том、波兰语的 tom 等许多语言中，它都指一本书的一卷。tomola 上的每篇帖子，也各自是一卷文字。

la 表示场所：法语和意大利语的 là、葡萄牙语的 lá 都是“那里”的意思，罗马尼亚语的 la 则表示“在”或“到”。我创建 tomola，是为了让使用任何语言的人，都能在同一个地方交谈。

在日语中，tomo 既是表示朋友的“友”，也是“共に”（一起）中的“共”。日语不区分 l 和 r 的音，所以 tomola 听起来也像“友ら”，也就是一群朋友。
