# Source Serif 4 provenance

The application imports `@fontsource-variable/source-serif-4/wght.css` and
`wght-italic.css`, unchanged, from npm package version 5.3.1. Its metadata
identifies Google Fonts revision v15, last modified 2026-10-01, from
https://github.com/google/fonts/tree/main/ofl/sourceserif4 . The npm package
repository is https://github.com/fontsource/font-files/tree/main/fonts/variable/source-serif-4 .

The distributed upright and italic WOFF2 files report font version
`Version 4.004;hotconv 1.0.116;makeotfexe 2.5.65601`. Their embedded copyright is:

> © 2014 - 2021 Adobe Systems Incorporated (http://www.adobe.com/), with Reserved Font Name ‘Source’.

The package's bundled OFL text starts with `Google Inc.`; it is reproduced
in the generated package entry. The Google Fonts OFL text, retrieved on
2026-10-17, is also included here as `source-serif-google-OFL.txt`; it names
The Source Serif 4 Project Authors. Retaining both notices records their
provenance; it does not resolve the difference between their attributions
and the embedded reserved-name notice. No font files were renamed or
modified in this change. Review reserved-name permissions before modifying
or redistributing a derived font under that name.
