# 公開の AI 向けの資料

話題の書き手は、投稿するとき、または `/t/:id/ai-materials/edit` で、公開の Markdown 資料を一つ付け、編集・削除できる。話題の頁には入口だけを出し、資料の本文と版の履歴は別の頁で読める。上限は UTF-16 で20,000文字。画像と数式は省く。資料は投稿時に保存し、サーバーの下書きには含めない。前もって訳さず、答えに付ける引用の訳は AI 訳と明記する。実在を照合するのは原文の引用で、訳の意味の正しさは保証しない。

資料は書き手の補足であり、AI への指示ではない。同じ Markdown の文法から、安全な表示と AI に渡す文を作る。HTML とコメント、使われないリンク・脚注の定義、リンク先と題、画像、数式は根拠から除く。TeX は文字を隠せるため、数式も省く。投稿の本文と返信の保存・表示は変えず、AI に渡すときだけ同じ処理を通す。Unicode のタグ文字、向きの制御、不要な非表示文字、通常でない制御文字は除く。文字参照で書かれたものも解析後に除く。ペルシア語の ZWNJ、文字間の接合文字、絵文字の ZWJ と表示選択子は残す。この処理で内容の真偽や安全性が確かめられるわけではない。

英語と日本語の固定規則で、指示の無視、AI の役割の指定、答えの強制に似た文を探す。保存は止めず、書き手に知らせる。規則に当たった記録は版ごとに残し、運営者だけが点検できる。公開の印は付けない。規則は言語に依存する不完全な手がかりで、指示を見抜く保証ではない。受け付ける時に意味を確かめきることはできない。

投稿ごとの AI には、本文・返信とは区別した欄で資料を渡す。文脈全体に上限を置き、いずれも信頼しないデータとして扱う。エンジンには道具、秘密、外部の取得、公開する機能、会員の非公開情報を渡さない。原文の引用が資料に実在することを照合し、出どころの種別、書き手、リンクはサイトが付ける。生成後にも、引用元が見え、変わっていないことを確かめる。切り詰めは知らせる。AI 訳は検証済みの訳ではない。文脈の区別と引用の照合は、読みの正しさを証明しない。

読む権限は話題と同じで、公開の閲覧が有効ならログインなしでも読める。話題または資料を隠すと、機械向けの出力と AI の根拠から、過去の版も含めて外す。書き手と担当のモデレーターは非表示の版を点検できる。書き換えと削除は書き手だけができ、モデレーターは書き換えない。話題の原文の言語を担当するモデレーターと運営者は、他者の資料を理由付きで非表示・再表示にでき、版の記録に残る。理由は公開の履歴に出さない。通報は資料の URL と版を添えて既存の話題の通報へ入り、同じ人による話題への通報枠を共用する。点検画面から資料へ進める。任意の AI による通報の優先付けには、通報された版の正規化した資料と話題の題だけを渡す。変更・非表示・削除された資料は渡さない。話題のモデレーションでも資料を外す。

資料を消すと版も消す。話題を消すと、同じトランザクションで資料と版も消す。読む人へ既に渡った答えやコピーは回収できない。会員のデータの書き出しには、本人の削除していない資料と版を、非表示のものも含めて入れる。資料は投稿の行、ホーム、検索、なるほど、通知、活動の数を増やさない。話題の Markdown と `tomola_thread` には、書き手の根拠だと記した `ai_supplement` の独立した欄で出す。外部の AI も信頼しない資料として読み、本文とは区別して出どころを示す。
